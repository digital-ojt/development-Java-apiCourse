## 1. API システム概要

### 1.1 API システムの責任範囲

本 API システムは **外部システム連携専用** の RESTful API サーバーです。

#### 1.1.1 主要機能

- **部品在庫管理 API** - 購買・生産システムとの部品入荷・出庫・在庫照会
- **製品在庫管理 API** - 生産・販売システムとの製品入庫・出荷・在庫照会
- **システム監視 API** - 外部監視システム向けヘルスチェック

#### 1.1.2 対象外機能（他システムの責任）

以下の機能は **WEB システム** または **BATCH システム** で提供されます：

| 機能分類           | 実装システム | 説明                           |
| ------------------ | ------------ | ------------------------------ |
| **管理画面**       | WEB          | カテゴリ管理、ユーザー管理     |
| **分析・レポート** | WEB + BATCH  | 履歴分析、統計レポート         |
| **アラート機能**   | WEB + BATCH  | アラート設定 + アラート生成    |
| **システム管理**   | WEB + BATCH  | 設定管理 + バックアップ処理    |
| **認証機能**       | WEB          | 管理者ログイン・セッション管理 |

### 1.2 外部システム連携方式

#### 1.2.1 連携対象システム

| システム名       | 連携方向 | 主要データ                           | 更新頻度     |
| ---------------- | -------- | ------------------------------------ | ------------ |
| **購買システム** | 双方向   | 部品入荷情報、入荷取消情報、在庫情報 | リアルタイム |
| **生産システム** | 双方向   | 生産指示、製品入庫情報、在庫情報     | リアルタイム |
| **販売システム** | 双方向   | 製品出荷情報、出荷取消情報、在庫情報 | リアルタイム |

#### 1.2.2 認証方式

**API キー認証** によるシステム間認証のみ実装：

```http
X-API-Key: <SYSTEM_API_KEY>
X-System-ID: <SYSTEM_IDENTIFIER>
Content-Type: application/json
```

| システム         | 権限レベル   | 利用可能 API                           |
| ---------------- | ------------ | -------------------------------------- |
| **購買システム** | SYSTEM_BUYER | 部品入荷、入荷取消、部品在庫照会       |
| **生産システム** | SYSTEM_PROD  | 部品出庫、出庫取消、製品入庫、在庫照会 |
| **販売システム** | SYSTEM_SALES | 製品出荷、出荷キャンセル、製品在庫照会 |

## 2. 部品在庫管理 API

### 2.1 API 一覧

| API 名           | エンドポイント              | メソッド | 説明                     | 対象システム |
| ---------------- | --------------------------- | -------- | ------------------------ | ------------ |
| **部品入荷**     | `/api/parts/receipt`        | POST     | 購買担当からの入荷処理   | 購買システム |
| **部品入荷取消** | `/api/parts/receipt/cancel` | POST     | 入荷キャンセル処理       | 購買システム |
| **部品出庫**     | `/api/parts/issue`          | POST     | 生産担当への部品出庫     | 生産システム |
| **部品出庫取消** | `/api/parts/issue/cancel`   | POST     | 製造計画変更時の出庫取消 | 生産システム |
| **部品在庫照会** | `/api/parts/stock`          | GET      | 部品在庫情報取得         | 購買・生産   |

### 2.2 認証・認可

- **認証方式**: API キー認証（`X-API-Key` ヘッダー）
- **対象システム**: 購買システム（入荷・入荷取消・在庫照会）、生産システム（出庫・出庫取消・在庫照会）
- **IP 制限**: 許可された外部システム IP からのアクセスのみ
- **レート制限**: 60req/min（システム別）

### 2.3 業務フロー対応

- 購買担当との連携（入荷・入荷取消）
- 生産担当との連携（出庫・出庫取消）
- リアルタイム在庫更新
- 冪等キーによる重複処理防止

## 3. 製品在庫管理 API

### 3.1 API 一覧

| API 名           | エンドポイント              | メソッド | 説明                 | 対象システム |
| ---------------- | --------------------------- | -------- | -------------------- | ------------ |
| **製品入庫**     | `/api/products/receipt`     | POST     | 製造完了後の製品入庫 | 生産システム |
| **製品出荷**     | `/api/products/ship`        | POST     | 販売担当への製品出荷 | 販売システム |
| **製品出荷取消** | `/api/products/ship/cancel` | POST     | 出荷キャンセル処理   | 販売システム |
| **製品在庫照会** | `/api/products/stock`       | GET      | 製品在庫情報取得     | 生産・販売   |

### 3.2 認証・認可

- **認証方式**: API キー認証（`X-API-Key` ヘッダー）
- **対象システム**: 生産システム（製品入庫・在庫照会）、販売システム（出荷・出荷取消・在庫照会）
- **IP 制限**: 許可された外部システム IP からのアクセスのみ
- **レート制限**: 60req/min（システム別）

### 3.3 業務フロー対応

- 生産担当との連携（入庫）
- 販売担当との連携（出荷・出荷取消）
- 品質検査済み製品の入庫管理

## 5. 共通エラーハンドリング

### 5.1 エラーコード定義

| エラーコード         | HTTP ステータス | 説明               |
| -------------------- | --------------- | ------------------ |
| `SUCCESS`            | 200             | 正常処理完了       |
| `INVALID_REQUEST`    | 400             | リクエスト形式不正 |
| `UNAUTHORIZED`       | 401             | 認証エラー         |
| `FORBIDDEN`          | 403             | 権限不足           |
| `RESOURCE_NOT_FOUND` | 404             | リソース未存在     |
| `DUPLICATE_REQUEST`  | 409             | 重複リクエスト     |
| `INSUFFICIENT_STOCK` | 422             | 在庫不足           |
| `INTERNAL_ERROR`     | 500             | システム内部エラー |

### 5.2 エラーレスポンス統一形式

```json
{
  "status": "error",
  "message": "エラーの概要説明",
  "error_code": "ERROR_CODE",
  "details": "詳細なエラー内容",
  "timestamp": "2024-12-15T10:30:15Z"
}
```

## 6. セキュリティ要件

### 6.1 認証・認可

#### 6.1.1 API キー認証

- **システム別固有キー**: 各外部システムに固有の API キーを発行
- **定期ローテーション**: セキュリティ強化のための定期的キー更新
- **アクセス制御**: システム権限に基づく機能制限

### 6.2 通信セキュリティ

- **TLS バージョン**: 1.2 以上
- **IP 制限**: 許可された外部システム IP からのアクセスのみ
- **レート制限**: システム別アクセス頻度制限（60req/min）
- **入力値検証**: 厳密なバリデーション実装

### 6.3 監査・ログ

- **API 呼び出しログ**: 全リクエストの記録
- **操作履歴**: 在庫変動の詳細ログ
- **セキュリティログ**: 認証失敗・不正アクセス記録
