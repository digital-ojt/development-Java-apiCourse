# 共通設計書

ドローン在庫管理システム全体で共通利用される設計書を管理しています。

## 📁 ファイル構成

```
共通/
├── README.md                # 本ファイル
├── システム概要.md          # システム全体のアーキテクチャ設計
└── データ要件.md            # データベース設計・データモデル設計
```

## 📊 設計書詳細

### システム概要.md

**目的**: システム全体のアーキテクチャ設計  
**内容**:

- ドローン在庫管理システムの全体構成
- ビジネス機能の配置と関係性
- バッチ処理・外部システム連携の設計
- システム間のインターフェース定義

**対象読者**:

- システムアーキテクト
- プロジェクトマネージャー
- 技術リーダー
- 新規参画メンバー

### データ要件.md

**目的**: データベース設計とデータモデル設計  
**内容**:

- データ設計方針と原則
- ER 図（概念データモデル）
- テーブル定義（物理データモデル）
- 命名規則とデータベース仕様

**対象読者**:

- データベースアーキテクト
- バックエンド開発者
- インフラエンジニア
- DBA（データベース管理者）

## 🎯 利用方法

### 新規参画時

1. **システム概要.md** でシステム全体像を把握
2. **データ要件.md** でデータ構造を理解

### 開発時

- API 設計時：データ要件を参照してテーブル関連を確認
- バッチ設計時：システム概要を参照して外部連携方式を確認

### 設計変更時

- システム構成変更：システム概要.md を更新
- テーブル変更：データ要件.md を更新
- 変更時は必ず関連チームへ共有
