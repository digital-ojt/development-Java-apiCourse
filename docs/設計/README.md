# アーキテクチャ設計書

本ディレクトリは、ドローン在庫管理システム全体のアーキテクチャ設計書を管理しています。

## 📁 ディレクトリ構成

```
architecture/
├── api/                    # APIシステムの設計書
├── batch/                  # バッチシステムの設計書
├── web/                    # Webシステムの設計書
└── common/                 # 全システム共通の設計書
```

## 🏗️ 各システムの設計構成

### API システム (`api/`)

RESTful API の設計書を管理しています。

#### 基本設計 (`api/basic-design/`)

- **`system-overview.md`** - API システム全体の概要と技術仕様
- **`interface-design.md`** - API インターフェース設計の詳細仕様
- **`api-functional-specifications.md`** - API 機能要件の仕様書

#### 詳細設計 (`api/detail-design/`)

- **`auth/`** - 認証・認可 API の詳細設計
- **`parts/`** - 部品管理 API の詳細設計
- **`products/`** - 製品管理 API の詳細設計
- **`categories/`** - カテゴリ管理 API の詳細設計
- **`history/`** - 履歴管理 API の詳細設計

### バッチシステム (`batch/`)

定期実行処理・バッチ処理の設計書を管理しています。

#### 基本設計 (`batch/basic-design/`)

- バッチシステム全体の概要設計（作成予定）

#### 詳細設計 (`batch/detail-design/`)

- 各バッチ処理の詳細設計（作成予定）

### Web システム (`web/`)

フロントエンド・Web UI の設計書を管理しています。

#### 基本設計 (`web/basic-design/`)

- Web システム全体の概要設計（作成予定）

#### 詳細設計 (`web/detail-design/`)

- 各画面・コンポーネントの詳細設計（作成予定）

### 共通設計 (`common/`)

全システムで共通利用される設計書を管理しています。

- **`system-overview.md`** - システム全体の概要
- **`data-design.md`** - データベース設計・データモデル設計
- **`operation-design.md`** - 運用設計・インフラ設計

## 📊 設計書の分類

### 基本設計 (Basic Design)

- システム全体の概要
- アーキテクチャ方針
- 技術選定
- インターフェース設計
- 機能要件

### 詳細設計 (Detail Design)

- 具体的な実装仕様
- データ構造定義
- API エンドポイント詳細
- 画面設計
- 処理フロー

## 🎯 設計書の利用目的

1. **開発チーム** - 実装時の参照資料
2. **品質保証** - テスト設計の基礎資料
3. **プロジェクト管理** - 進捗管理・工数見積もり
4. **保守運用** - 運用時の参考資料
5. **新規メンバー** - システム理解のためのオンボーディング資料
