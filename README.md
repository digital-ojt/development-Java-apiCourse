# ドローン在庫管理 API (DroneInventorySystem)

システム
製造業クライアント向けのドローン在庫管理システム です。

## カリキュラム概要

### 学習目的

本プロジェクトは【Java 開発コース】の実践的な学習教材として開発されています。実際の業務開発に近い環境での学習体験を提供することを目的としています。

### 仮想案件について

このシステムは**amoibeOJT**における仮想案件として設定されており、以下の特徴があります：

- 実在の企業要件を模倣した仕様設計
- 実務レベルの技術要件とアーキテクチャ
- 段階的な機能開発による学習進行
- 設計、実装、試験工程の実践

## 📁 ドキュメント構成

### 要件定義ドキュメント

要件定義フェーズで作成されたドキュメント群は、[docs/要件定義/](docs/要件定義/) フォルダーに配置されています。

#### 📄 [1.業務要件.md](docs/要件定義/1.業務要件.md)

- **目的**: プロジェクトの背景、目的、業務プロセスを定義
- **対象読者**: プロジェクトマネージャー、ビジネスアナリスト、ステークホルダー、開発チーム
- **主要内容**:
  - **プロジェクト概要**: ドローン製造業の課題と解決方針
  - **クライアント企業情報**: 産業用ドローン製造業（2016 年創業）の概要
  - **業務プロセス**: 部品購買・入荷、製品製造、出荷の各プロセス
  - **マスタ情報管理**: 部品・製品・在庫センター管理
  - **ビジネスルール**: 在庫管理・品質管理・トレーサビリティ要件
  - **ステークホルダー**: 購買・生産・販売・品質管理各担当者の役割

#### 📄 [2.機能要件.md](docs/要件定義/2.機能要件.md)

- **目的**: システムが提供すべき機能を詳細に定義
- **対象読者**: システムアーキテクト、開発チーム、テストエンジニア、システムインテグレーター
- **主要内容**:
  - **認証・認可機能**: JWT 認証、役割ベースアクセス制御
  - **在庫管理機能**: 部品・製品在庫の一元管理
  - **履歴管理機能**: 入荷・出荷・操作履歴の完全記録
  - **アラート機能**: 在庫不足・過剰の自動検知と通知
  - **カテゴリ管理機能**: 部品・製品の分類管理
  - **API 仕様**: RESTful API 設計とエンドポイント定義
  - **ユーザーストーリー**: 各機能のユーザー視点での価値定義

#### 📄 [3.非機能要件.md](docs/要件定義/3.非機能要件.md)

- **目的**: システムの品質要件と技術的制約を定義
- **対象読者**: システムアーキテクト、インフラエンジニア、開発リーダー、品質保証エンジニア、運用チーム
- **主要内容**:
  - **性能要件**: 応答時間（API: 1-3 秒）、スループット（50 同時接続）
  - **可用性要件**: 稼働率 99.5%以上、障害回復時間 4 時間以内
  - **拡張性要件**: 垂直・水平スケーリング対応
  - **セキュリティ要件**: JWT 認証、RBAC、データ暗号化
  - **保守性要件**: 運用監視、ログ管理、バックアップ
  - **互換性・移植性要件**: 標準技術採用、環境非依存
